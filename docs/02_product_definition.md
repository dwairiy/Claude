# 02: Product Definition: AL MOHIB **SAKINA** Series

> Brand: **AL Mohib Trading / المهيب التجارية** (client logo: `brand/al_mohib_logo.png`)
> Product: invented for this portfolio film. It is modelled on the premium slimline system-aluminium category, not on any specific competitor product.

## ⚠ Brand note to resolve before anything is printed
The Arabic and English names on the logo don't match:
- **المهيب** reads *Al-Muhīb / Al-Mahīb* ("the revered, the formidable").
- **"Mohib"** in English would normally be written **محب / المحب** ("the loving one").

Pick one and align both scripts. If المهيب is correct, use **"AL MUHIB"** or **"AL MAHEEB"** in English. Every super, end card and voiceover in the film depends on this choice.

## Positioning
| | |
|---|---|
| **Line name** | **SAKINA (سكينة)**, meaning tranquility or inner calm. The name carries the product benefit and the film's idea, and it works in both Arabic and English. |
| **Category** | Slimline, thermally broken, acoustic aluminium sliding system |
| **Promise** | *All of the view. None of the noise.* (Arabic option: **المنظر كله… بلا ضجيج**) |
| **Audience** | High-rise residents, villa owners, architects and developers in KSA/GCC |
| **Proof pillars** | 1) Acoustic calm · 2) Slim sightlines and full view · 3) Heat control for the Gulf · 4) Security |

## Spec sheet (fictional, kept within realistic category limits)
| Item | SAKINA S20 |
|---|---|
| Visible interlock | **20 mm** ultra-slim |
| Thermal break | 24 mm polyamide strips, Uf ≈ 2.4 W/m²K |
| Glazing | Acoustic laminated DGU, 8 + 16 Argon + 10.76 acoustic PVB, up to 44 mm |
| Sound reduction | **Up to Rw 42 dB** (busy road becomes a quiet library) |
| Solar control | Low-E coating, SHGC 0.28, built for Gulf heat |
| Sash size / weight | Up to 3.2 m wide × 3.5 m high, 400 kg per sash |
| Sealing | Triple EPDM gaskets plus brush-pile seals, pressure-equalised drainage |
| Security | Concealed multipoint lock (3 hooks), anti-lift blocks |
| Track | Flush threshold, 2-, 3- or 4-track and corner-opening versions |
| Finishes | Matte Black (hero), Champagne Anodised, Bronze, Signature Navy (brand colour) |
| Warranty | 15-year profile and finish |
